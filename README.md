# Archive Line Index

A Python library with a minimal single-target CLI for sequential archive payload streaming and byte-line indexing. The [project brief](docs/dev/PROJECT.md) defines intended scope. Implementation has not started.

Development uses [SDD Manager](SDD-MANAGER.md). See the [AI-assisted development disclosure](AI_DISCLOSURE.md).

[Architecture](docs/dev/ARCHITECTURE.md), [specification](docs/dev/SPEC.md), [delivery plan](docs/dev/PLAN.md) and [implementation tasks](docs/dev/TASKS.md) describe the intended system and its delivery.
